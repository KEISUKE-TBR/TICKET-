# Card Studio

ブラウザだけで動く、Figmaライクなカードデザイン／差し込み印刷エディターの基礎版です。

## 起動

`index.html` をChromeで開いてください。GitHub Pagesにもそのまま配置できます。

## 実装済み

- 86×54mmの横カード
- 54×86mmの縦カード
- 縦カードを印刷時だけ90度回転
- レイヤー一覧
- 前面／背面
- 複製／削除
- Undo／Redo
- 文字
- Google Fonts
- 四角形、円、線
- 画像
- 位置、サイズ、回転、透明度
- ズーム
- CSV差し込み
- 差し込みプレビュー
- ELECOM MT-HMN2WNRの2列×4段面付け
- `.cardstudio` JSON保存／読込

## 重要

これはFigmaそのものを再実装した完成品ではなく、Card Studioのアーキテクチャと操作感を検証するための実用プロトタイプです。

次段階では以下を追加できます。

- 複数選択
- スマートガイド／スナップ
- ペンツール
- SVG編集
- グループ
- マスク
- オートレイアウト
- 両面カード
- 複数ページ
- テンプレート用紙プリセット管理
- 高精度PDF書き出し
- Google Sheets連携
