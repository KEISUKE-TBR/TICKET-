# Card Layout Studio

CSVの各行をカードデザインへ差し込み、エレコム MT-HMN2WNR（A4・8面）向けに自動面付けして印刷／PDF保存するブラウザアプリです。

## 起動方法

1. `index.html` をGoogle Chromeで開きます。
2. 「CSVデータ」でCSVを読み込みます。
3. 列の割り当てを確認し、「割り当てを適用」を押します。
4. 「デザイン」でプレースホルダーの位置・サイズ・文字設定を調整します。
5. 「配置・印刷」で8面レイアウトを確認します。
6. 必要なカードをクリックして、そのカードだけ文字サイズや位置を調整します。
7. 「印刷 / PDF保存」を押します。

サーバーは不要です。CSV内容、メッセージ、QRコードはブラウザ内だけで処理します。

## 対応CSV列

列名は自由です。読み込み後に以下へ割り当てます。

- 管理ID
- 贈り主
- メッセージ
- QR画像URL / QR内容

QR列について：

- `https://...`：画像URLとして読み込み
- `data:image/...`：画像データとして読み込み
- `=IMAGE("https://...")`：最初のURLを抽出
- URL以外：QuickChartのQR画像URLへ変換

## 印刷用紙プリセット

- 用紙：A4縦 210 × 297mm
- カード：86 × 54mm
- 2列 × 4段
- 左右余白：14mm
- 上下余白：25.5mm
- 列間：10mm
- 段間：10mm

カード左上座標：

1. 14, 25.5
2. 110, 25.5
3. 14, 89.5
4. 110, 89.5
5. 14, 153.5
6. 110, 153.5
7. 14, 217.5
8. 110, 217.5

## 推奨印刷設定

- 用紙：A4
- 向き：縦
- 倍率：100% / 実際のサイズ
- 用紙に合わせる：OFF
- 余白：なし
- ヘッダーとフッター：OFF
- 背景のグラフィック：デザインに背景色・画像がある場合はON

最初は普通紙に「テスト枠あり」で印刷し、用紙を重ねて位置を確認してください。プリンター固有のズレは「横補正」「縦補正」で調整できます。

## データ保存

テンプレート、個別調整、印刷補正はブラウザの `localStorage` に保存されます。CSVデータは保存しません。

別PCへテンプレートを移す場合は「JSONを書き出す」「JSONを読み込む」を利用してください。

## 現在の制限

- PDFファイルをアプリから直接生成するのではなく、Chromeの印刷画面から「PDFに保存」を選択します。
- Googleスプレッドシートへの直接接続は未実装です。CSVをダウンロードして読み込みます。
- 外部QR画像URLは、印刷時にもインターネット接続が必要です。
- Webフォントの自動埋め込みは行いません。端末にあるフォントを使用します。
- 両面印刷の裏面並び替えは未実装です。


## デザイン機能（拡張版）

ローカルフォント読込、フォント選択、文字色、字間、行間、太さ、イタリック、背景色、枠線、透明度、回転、角丸、画像トリミングに対応しました。ローカルフォントは再読み込み後にもう一度選択してください。
